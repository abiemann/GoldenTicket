Do not tap through a warning. If the browser offered “Advanced”, “Proceed anyway”, “Show details” or “Visit this website”, stop and go back. The laptop's certificate has not been trusted properly yet, and tapping through hides that instead of fixing it. Install the certificate from the laptop's setup page first, then return here and reload. On iPhone and iPad, installing the profile is only half of it: turn the certificate on in Settings → General → About → Certificate Trust Settings.

2 · Install to the home screen

Do this before pairing. A browser tab and the installed app keep separate cookies and storage, so a pairing code spent in a tab can leave the installed app still unpaired.

Install first. This is still a browser tab, so a code redeemed here may not carry into the home-screen app. Finish step 2, open the app from the home screen, and pair there.
